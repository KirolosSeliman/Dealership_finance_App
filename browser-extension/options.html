Deep Capture Mode

Active by default - consent UI pending

Deep Capture is temporarily active by default for authorized OpenLane pages while the installer/onboarding consent box is being added. Formal Deep Capture persistence still requires affirmative consent from an authorized Dealer Flow organization user. The client is authorized only to capture visible vehicle/listing/business data from pages they are allowed to access.

  • Normal capture reads visible listing fields for Market Snap analysis.
  • Deep Capture may include safe read-only section expansion, visible page-loaded JSON response summaries, media URL metadata, condition/disclosure evidence, bid/offer observations, and visible post-sale or fee/invoice details.
  • Model improvement is a separate opt-in. Active current bids are not training labels.
  • No CAPTCHA bypass. No anti-bot bypass. No login-wall bypass. No hidden request manipulation.
  • No credential, cookie, token, or session capture. Consent can be withdrawn.

View captured JSON and Copy extracted JSON are available in the in-page widget. Copied debug payloads redact secrets before they leave the page.

Status labels: Active by default - consent UI pending; On - active consent; Off - disabled or missing settings; Paused - backend unreachable; Requires renewal - consent version changed.

Use only authorized/user-assisted listing capture. This extension does not bypass login walls, CAPTCHAs, rate limits, access controls, or platform restrictions.
