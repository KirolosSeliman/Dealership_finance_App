# Phase 07 — Page-Generated Network Observation

## Mission

Optionally observe structured data responses the OpenLane page already loads.

## Root problem

OpenLane may render VIN/photos/disclosures/fees from structured JSON that is more reliable than DOM text.

## Consequences

Second order: DOM-only extraction remains fragile.  
Third order: layout changes break fields.  
Fourth order: Market Snap cannot scale reliably.

## Required solution

Implement safe network observation.

Rules:
- Do not create new OpenLane requests.
- Do not call hidden endpoints manually.
- Do not crawl.
- Only observe responses generated by the current page the user opened.
- Sanitize and cap payloads.
- Do not capture cookies, auth headers, tokens, credentials, or unrelated personal data.

Implementation:
- inject page-context script to wrap `fetch`/`XMLHttpRequest`
- clone responses safely
- inspect only relevant content-type/URL/JSON shape
- emit sanitized vehicle/listing/purchase candidates to content script
- score candidates; do not blindly trust network data
- add debug showing observed endpoint pattern and sanitized keys
- add setting if needed: `observePageNetworkData`

## Acceptance criteria

- Tests mock page fetch/XHR and recover VIN/media/condition candidates.
- No new OpenLane network requests are made.
- Secret/token strings are not captured.
- DOM extraction still works without network evidence.
